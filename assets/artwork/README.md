# README artwork

Two original concept illustrations were generated for this project with the
built-in image-generation tool on 2026-11-03.

| Asset | Direction |
| --- | --- |
| [Cover](zenbook-duo-linux-hero.png) | Midnight-blue studio render of a dual-screen Zenbook Duo-style laptop, cyan displays, detached keyboard and Linux Tux. |
| [Field notes](zenbook-duo-linux-field-notes.png) | Matching technical illustration with fine cyan lines and a drafting grid. |

These illustrations are decorative artwork, not photographs of the tested laptop
or authentic desktop screenshots. Hardware observations remain in the machine
profiles and evidence directories. The original PNG output is copied unchanged;
generation metadata is preserved.

The complete final prompts, image dimensions and checksums are recorded in
[generation.json](generation.json). The companion badges in `../badges/` are
small project-authored SVG labels, not official project logos or support badges.
