# Machine profile: MODEL / DISTRO

- Identity and evidence: product, board, generation, CPU/GPU, memory, keyboard IDs.
- Firmware: exact BIOS/date and firmware packages; update status unknown until checked.
- Environment: native/live/WSL/chroot, OS, kernel, desktop, display manager, shell.
- Storage: observed device identity, filesystems/encryption, bootloader, recovery media, backup state; destructive authorization if relevant.
- Existing Duo software: services, files, ownership and source commits.
- Baseline features: boot, displays, touch/pen, rotation, brightness, keyboard/touchpad, audio, network, suspend/lid, battery/power.
- Selected route and alternatives considered, with dated source references.
- Applied changes and effective verification; untested features explicit.
- Open issues, rollback and next action.
- Evidence links and source provenance.

Create a corresponding state.json and dated journal. Do not populate identity or support claims by copying another model's results.
