## Learnings for future sessions

- `journalctl -k` exports from this workflow are safe for publication after a
  targeted MAC scan; username/hostname appear but no secrets. Scan for
  `([0-9A-Fa-f]{2}:){5}` before publishing anyway.
- `/boot` on this machine is not readable by the agent user; batch all root-only
  inspection into one sudo script for the user to run instead of asking piecemeal.
- The kernel advanced 7.3.1 → 7.3.3 between the incident and this session; any
  future freeze logs must be matched to their kernel version before comparison.
- CachyOS ships `linux-cachyos-lts`; a same-generation LTS fallback exists for
  recovery but is not yet validated on this hardware.
